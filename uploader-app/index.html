Uploader App

Uploader App is a small personal tool that uploads video files from the developer's own home server to the developer's own Google Drive accounts.

What it does

  • Uploads finished video files (.mp4) to a Google Drive folder.
  • Keeps a backup copy of project files in a second Google Drive account.
  • Moves older videos in the upload folder to the Drive trash, so the folder does not fill up.

Who uses it

Only the developer. The app is not offered to the public and has no other users.

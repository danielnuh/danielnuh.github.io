Uploader App — Privacy Policy

Last updated: 28 October 2026

Uploader App is a personal tool run by its developer on the developer's own server. It is used only with the developer's own Google accounts.

Data the app accesses

After the developer signs in with Google, the app can access files in the signed-in Google Drive account. It uses this access to:

  • list the contents of a chosen folder,
  • upload video files and verify their size,
  • move older videos in that folder to the Drive trash.

How data is used and stored

  • The sign-in token is stored only on the developer's own server, in a file readable only by the developer.
  • The app does not send Google user data to any other server or service.
  • The app does not collect, sell, share, or transfer Google user data to third parties.
  • No advertising, analytics, or profiling of any kind.

Google API Services User Data Policy

Uploader App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions, or by deleting the token file on the server.
